# Optix coworking evaluation stub

> This is an incomplete evaluation stub, not an implementation guide.

## Verified snapshot

Optix is proprietary managed SaaS/mobile software for booking and community/member experience. Public list pricing is unverified in the catalog and should be obtained from the vendor. It may hold users, bookings, community content, and personal data.

Sources reviewed **2026-07-17**: [homepage](https://www.optixapp.com/), [support](https://support.optixapp.com/), and [pricing](https://www.optixapp.com/pricing/).

## Evaluation questions

- Which member experience problem requires a mobile app?
- What are current contract, app-store, implementation, integration, and support terms?
- Can users, bookings, and content be exported completely?
- How will members without the app book or receive support?

## Smallest experiment

Pilot booking UX for a single floor with test or approved users and survey 15 members about friction. Keep a manual booking route and test export before expansion.

## Risks

- Proprietary vendor, contract, and app-store dependency
- Member adoption, accessibility, and integration cost
- Unverified pricing, exports, privacy terms, and fallback behavior
