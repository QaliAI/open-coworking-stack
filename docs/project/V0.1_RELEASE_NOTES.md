# Open Coworking Stack v0.1.0 — Release Notes

Released 2026-10-22.

## What this is

A free and open-source directory of technology for coworking and flexible-workspace operators:
structured catalog records, coworking-specific evaluation guidance, reference stacks, implementation
guides, and a generated documentation site. It is a decision aid, not a hosted SaaS product and not a
ranking.

## Highlights

- **116 tool records** across sales, marketing, operations, member experience, finance and
  administration, and technology and security. Every record carries a license class (open source,
  open-core, source-available, fair-code, freemium, proprietary), a cost-model note, the work that
  stays with your team, and privacy/security notes.
- **14 reference stacks** and **75 workflows**, with starter Docker Compose packs and n8n workflow
  examples as technical demonstrations.
- **105 operator tasks** and **14 operator roles** mapped to candidate tooling.
- **22 comparison pages**, each labeled as a directional shortlist or due-diligence worksheet.
- **Stack Builder**: compares hosted, hybrid, and self-hosted operating models, links tools to their
  catalog records and installation guides, and includes a capacity and payback estimator with
  editable assumptions. It promises no savings; the sample numbers are fabricated demonstrations you
  replace with real quotes.
- **Start Here pathway**: a five-step operator path from problem definition to a small pilot.
- 25 tools have a full installation guide; 26 have a labeled stub; the rest are planned.

## Repository contents

- `catalog/` — canonical YAML tool, stack, and workflow records with JSON Schema mirrors
- `packages/` — Zod schemas, validators (schema, business rules, freshness), and generators
- `apps/web/` — Astro + Starlight documentation site (the generated pages are build artifacts)
- `guides/`, `stacks/`, `compose/` — human-written guides, reference stacks, and Compose starter packs
- `docs/` — architecture, security, and release documentation

## Verification performed for this release

Release checks were run on the release candidate: dependency install (locked), formatting, lint,
type-checking, catalog validation, generation, unit tests, production build, Playwright browser
tests, accessibility (axe) tests, and external/internal link checking. Results are recorded in
`docs/project/RELEASE_READINESS.md` and the release checklist.

## Honest limits

- Zero tools are labeled "Verified Core"; a listing is not an endorsement.
- No adoption numbers, GitHub-star counts, savings, ROI, or staff-reduction claims are made.
- Pricing, licensing, privacy, and security details must be re-checked against official sources
  before any production decision.
- Compose packs are demonstrations with placeholder secrets; they are not production-certified or
  runtime-tested systems.
- Comparison depth is partial; flagship comparisons carry sourced evidence markers.
