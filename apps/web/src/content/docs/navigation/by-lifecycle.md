---
title: Navigate by lifecycle
description: Nine phases from validating a coworking concept through renewal, migration, or closure.
---

Use the current phase to find the next operating decision. A phase is not a maturity badge: revisit
earlier phases when ownership, products, locations, law, vendors, or technical capacity change.

## 1. Validate

Define the member problem, service promise, location assumptions, manual baseline, risks, and stop
condition before selecting software.

- Start with [buy vs build vs self-host](../../ops/buy-build-self-host/).
- Compare [owner-operator tasks](../../roles/generated/owner-operator/).
- Use the [ROI calculator](../../roi-calculator/) only with your own measured baseline.

## 2. Plan

Map products, roles, workflows, data, systems of record, approvals, budget, professional boundaries,
manual fallback, and exit requirements.

- Define the [canonical data and portability boundary](../../ops/data-portability/).
- Browse [roles](../by-role/) and [operator problems](../by-problem/).
- Record recurring labor, not only software cash.

## 3. Select

Compare complete operating models and evidence, not feature lists. Confirm license, pricing, privacy,
security, export, accessibility, support, and maintenance facts against current official sources.

- Use the [Stack Builder](../../stack-builder/).
- Browse [business models](../by-business-model/), [technical ability](../by-technical-ability/), and
  [budget](../by-budget/).
- Read the [evaluation criteria](../../start/evaluation-criteria/).

## 4. Implement

Configure one isolated, reversible pilot with synthetic data. Name business, data, privacy/security,
technical, and functional owners.

- Use [starter packs](../../guides/starter-packs/) only as non-production references.
- Follow the [security baseline](../../guides/security-baseline/) and
  [backup/restore guide](../../guides/backup-and-restore/).
- Keep unrun [runtime stages](../../ops/runtime-validation/) marked pending.

## 5. Launch

Reconcile migration, permissions, money, access, communications, fallback, support, and rollback before
introducing members or consequential automation.

- Rehearse [member onboarding](../../workflows/generated/member-onboarding/).
- Test [room booking](../../workflows/generated/room-booking/) and
  [tour-to-close](../../workflows/generated/tour-to-close/) exceptions.
- Obtain required [professional review](../../ops/professional-help/).

## 6. Operate

Run the service with named queue owners, daily reconciliation, member-facing alternatives, access
reviews, patches, backup checks, and documented incidents.

- Follow the [maintenance cadence](../../ops/maintenance/).
- Browse operational [tasks](../../tasks/generated/open-front-desk/).
- Keep consequential decisions and service recovery with people.

## 7. Grow

Improve qualified demand, conversion, retention, utilization, and product fit without weakening
consent, service, capacity, or financial controls.

- Review [growth and sales](../../stacks/generated/growth-and-sales/).
- Map [marketing campaigns](../../workflows/generated/marketing-campaigns/) and
  [member feedback](../../workflows/generated/member-feedback/).
- Measure quality, exceptions, and labor alongside revenue.

## 8. Scale

Add products, staff, integrations, or locations only after the first operating unit has accepted
procedures, recovery, and local exception ownership.

- Evaluate the [multi-location stack](../../stacks/generated/multi-location-operator/).
- Stage the [multi-site rollout](../../workflows/generated/multi-site-rollout/).
- Re-test data authority, privileged access, support coverage, and recovery at each site.

## 9. Renew or exit

Reassess vendor terms, observed outcomes, labor, incidents, ownership, portability, and alternatives.
Renewal is a new decision, not an automatic continuation.

- Run [vendor renewal](../../workflows/generated/vendor-renewal/) and
  [vendor offboarding](../../workflows/generated/vendor-offboarding/).
- Test a reconciled export against the [portability model](../../ops/data-portability/).
- Revoke access, preserve only required records, rotate credentials, and close member/staff loops.
