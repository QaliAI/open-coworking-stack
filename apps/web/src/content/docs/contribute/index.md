See the repository [CONTRIBUTING.md](https://github.com/open-coworking-stack/open-coworking-stack/blob/main/CONTRIBUTING.md).

Quick path:

1. Copy `catalog/tools/_template.yaml`
2. Add `guides/tools/<id>.md`
3. Run `pnpm check`
4. Open a pull request
