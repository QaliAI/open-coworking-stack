## How to use this site

<ol class="ocs-steps">
  <li>
    <strong>Pick one job.</strong> Start with the task that eats the most time: tour booking, room
    booking, invoices or the member newsletter. Don't try to replace everything at once.
  </li>
  <li>
    <strong>Compare a few options.</strong> Every listing shows the price, whether you need your own
    server, how hard setup is and what your team still handles by hand. The{' '}
    <a href="./comparisons/">side-by-side comparisons</a> help you choose.
  </li>
  <li>
    <strong>Try it small.</strong> Test with one location, a few friendly members or dummy data
    before you move everyone over. The <a href="./guides/">setup guides</a> walk you through it.
  </li>
</ol>

## Good to know before you pick

<ul class="ocs-notes">
  <li>
    <strong>Free doesn't mean zero work.</strong> Open-source tools are free to use, but if you host
    them yourself you need a server and someone to keep them updated and backed up.
  </li>
  <li>
    <strong>Paid tools are labelled.</strong> Some listings are paid products or have paid upgrades.
    They are included so you can compare, and every listing shows its cost.
  </li>
  <li>
    <strong>Some listings are still being checked.</strong> Tools marked "Not yet reviewed" look
    promising, but confirm pricing and features on the official site before you commit.
  </li>
  <li>
    <strong>Nobody pays to be listed.</strong> Listings are not ads. Prices and plans change, so
    always confirm on the official site.
  </li>
</ul>
