Use these pages to shortlist an operating model, not to skip a pilot. Each page is classified so you
know what evidence to expect before you click. `Partial` means official material supports only part
of the decision; `not established` means this library has not verified the claim. Prices, free
limits, and edition-specific entitlements are intentionally omitted.
