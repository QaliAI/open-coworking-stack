# Coworking technology taxonomy

This taxonomy organizes tools by **operator problems**, not vendor marketing categories.

## Categories

| Category                   | Operator intent                          |
| -------------------------- | ---------------------------------------- |
| `access-control`           | Who can enter spaces and when            |
| `membership-crm`           | Members, leads, accounts, relationships  |
| `booking-scheduling`       | Rooms, desks, tours, appointments        |
| `billing-payments`         | Invoices, subscriptions, payment capture |
| `accounting`               | Books, cashflow, financial reporting     |
| `community-engagement`     | Programs, community channels, feedback   |
| `communication-chat`       | Staff/member messaging                   |
| `email-marketing`          | Newsletters and campaigns                |
| `website-cms`              | Public web presence and content          |
| `forms-surveys`            | Structured intake and surveys            |
| `helpdesk-support`         | Tickets and shared inboxes               |
| `knowledge-base`           | SOPs and FAQs                            |
| `event-management`         | Events lifecycle                         |
| `mailroom-virtual-office`  | Mail/packages/virtual office             |
| `facility-operations`      | Cleaning, maintenance, assets            |
| `network-wifi`             | Connectivity and segmentation            |
| `identity-sso`             | Login, SSO, joiners/leavers              |
| `file-storage`             | Documents and files                      |
| `password-secrets`         | Credentials and secrets                  |
| `automation-integration`   | Glue between systems                     |
| `analytics-bi`             | Metrics and dashboards                   |
| `monitoring-observability` | Uptime and infra health                  |
| `backup-recovery`          | Backups and restore drills               |
| `video-conferencing`       | Meetings and hybrid events               |
| `digital-signage`          | Visual communications                    |
| `pos-retail`               | Merchandise and pass sales               |
| `project-work-management`  | Internal projects/tasks                  |
| `legal-contracts`          | Agreements and e-sign                    |
| `hr-people`                | Staff HR (out of core v1 depth)          |
| `security-compliance`      | Security controls and compliance support |
| `developer-platform`       | Building blocks for custom systems       |
| `maps-wayfinding`          | Wayfinding and maps                      |
| `iot-sensors`              | Sensors and building telemetry           |
| `other`                    | Does not fit cleanly                     |

## Roles

See `RoleSchema` in `@ocs/schema`. Navigation pages map each role to problems and starter stacks.
