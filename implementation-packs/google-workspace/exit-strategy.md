# Exit strategy

1. Inventory domains, aliases, users, groups, shared drives/files, calendars, forms/responses, guests, app grants, retention settings, and ownership dependencies.
2. Select and test a target for each required data type; document unsupported metadata/history/permissions.
3. Migrate a representative cohort and reconcile counts, usability, ownership, calendar behavior, mail routing if later applicable, and open tour leads.
4. Approve domain/DNS and identity cutover with a tested return path and out-of-band contacts.
5. Transfer/reconcile all open work, revoke guests/apps/sessions, and retain read access only as approved.
6. Cancel/delete only after contractual, legal, retention, and recovery approvals.

Professional migration and legal/privacy review may be required. This pack makes no portability or deletion-completion claim.
