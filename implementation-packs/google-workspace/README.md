# Google Workspace implementation pack

Use this pack to pilot one controlled staff shared-drive structure and one minimal tour-request form. It does not authorize a domain/mail migration or establish plan features, privacy compliance, residency, certifications, support, backup, or production readiness.

Confirm the actual subscription and controls, approve the checklist, follow `recipes/shared-drive-tour-form.md`, and record observed results. The example is synthetic.

Official sources reviewed 2026-07-17: [Google Workspace](https://workspace.google.com/), [pricing](https://workspace.google.com/pricing.html), and [administrator help](https://support.google.com/a/). Re-check current terms, plan capabilities, and documentation before configuration.
