# Recipe: shared drive and tour form pilot

1. Create a pilot group containing only named staff and assign a manager-approved owner.
2. Create function-based shared-drive folders and add only representative non-sensitive files.
3. Test intended staff access, blocked link/external access, one explicitly approved guest, and revocation.
4. Create a form with only approved contact/request fields, notice, retention, response destination, and named human lead owner.
5. Submit synthetic responses; verify notification, human qualification, manual-register fallback, and deletion.
6. Suspend a synthetic leaver account and verify ownership/access handling.
7. Export representative records and document usability plus missing metadata.

Exact settings vary by current edition and admin controls; record observed settings rather than assuming labels or availability.
