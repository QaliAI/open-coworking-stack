# Configuration checklist

- [ ] Record actual edition, billing owner, terms review, support path, and observed controls.
- [ ] Use separate named administrators with approved strong authentication and recovery.
- [ ] Record domain/DNS ownership; make no pilot mail cutover.
- [ ] Create function-based groups and shared drives with named business owners.
- [ ] Approve internal, guest, link-sharing, download, and revocation rules actually available.
- [ ] Build the tour form with minimum approved fields, retention, notice, and lead owner.
- [ ] Define joiner/leaver suspension, transfer, deletion, and evidence steps.
- [ ] Require review for OAuth/marketplace apps and exceptional sharing.
- [ ] Record incident contacts and out-of-band staff/tour fallback.
- [ ] Test representative exports and determine independent backup needs.
- [ ] Obtain account, domain, privacy/data, security, manager, and lead approvals.
