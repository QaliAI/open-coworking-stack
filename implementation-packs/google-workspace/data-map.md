# Data map

| Data                   | Purpose                         | Approved access       | Exit/recovery check                                       |
| ---------------------- | ------------------------------- | --------------------- | --------------------------------------------------------- |
| Staff accounts/groups  | Collaboration access            | Named admins/managers | Account/group roster and migration plan                   |
| Shared-drive files     | Operational documents           | Approved staff/groups | Representative export opens with metadata limits recorded |
| Calendar data          | Coordination if tested          | Approved staff        | Representative export/import check                        |
| Staff email            | Communication if in scope later | Account owner/users   | Separate mail migration test; excluded from pilot cutover |
| Tour responses         | Human lead follow-up            | Named lead group      | CSV/manual lead register reconciliation                   |
| Guest links/app grants | Controlled collaboration        | Admin/data owner      | Revoke and evidence review                                |

Minimize form fields and file sensitivity. Payment data, identity documents, access credentials, health/HR data, and legal records are excluded unless separately approved with professional review.
