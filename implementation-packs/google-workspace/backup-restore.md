# Backup, export, and recovery

Managed availability is not operator-controlled backup. Inventory required mail, files, calendars, forms, accounts/groups, shared ownership, app grants, and configuration. Verify current supported export/migration paths for the actual edition, then decide whether an independently governed backup service is required.

Export representative non-sensitive records. Verify files open, calendars import where tested, messages remain usable if later in scope, form responses reconcile, and ownership/permissions metadata limitations are documented. Exercise non-critical admin recovery.

Do not call this a full restore unless the required objects, metadata, permissions, versions, and recovery objective were actually restored and evidenced.
