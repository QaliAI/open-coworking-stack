# Caddy implementation pack

Use this pack to pilot Caddy as the HTTPS reverse proxy for one non-critical coworking service. It is an operator checklist, not vendored Caddy code or proof that a deployment is production-ready.

Start with `operator-profile.yaml`, approve `configuration-checklist.md`, run `recipes/staging-proxy.md`, and record results with `templates/test-record.md`. `examples/test-record.md` is synthetic and is not evidence from a live deployment.

Official sources reviewed 2026-07-17: [documentation](https://caddyserver.com/docs/), [homepage](https://caddyserver.com/), and [repository](https://github.com/caddyserver/caddy). Re-check version-specific documentation before use.
