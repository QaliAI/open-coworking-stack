# Coworking use cases

## Pilot use case

Publish one staging help desk, wiki, or booking test service at an approved hostname. Success means reviewed HTTPS routing and a rehearsed return to the old route.

## Useful extensions after a new approval

- Add another internal service only after separate host, data, authentication, and rollback review.
- Add approved security headers only after application compatibility tests.
- Enable minimized access logging only for a documented operational purpose and retention period.

## Not a use case

Caddy does not grant member/staff rights, repair application vulnerabilities, decide incident severity, or replace an application outage process.
