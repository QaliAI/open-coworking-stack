# BookStack pilot plan

## Select

Choose five current documents: opening, closing, emergency, member FAQ, and one facilities or sales procedure. Complete `templates/content-register.csv`; reject ownerless or conflicting sources.

## Build

Create private staging, roles, shelves/books, and one page template. Migrate text and attachments while preserving source references and review metadata.

## Test

Have editor and reader complete representative tasks. Use an unauthorized session to test private denial. Export one page/book as supported, restore all instance state cleanly, and verify the five pages and roles.

## Decide

Knowledge owner accepts accuracy/findability; technical owner accepts permissions/recovery; qualified reviewers accept critical pages. Otherwise freeze publication and reconcile sources. Runtime behavior remains untested until recorded.
