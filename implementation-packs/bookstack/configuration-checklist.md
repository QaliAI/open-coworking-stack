# BookStack configuration checklist

- [ ] Exact BookStack release, package/container source, and dependencies recorded
- [ ] Canonical `APP_URL`, TLS, reverse proxy, and time zone verified
- [ ] `.env`, `APP_KEY`, database, uploads, attachments, and themes protected
- [ ] Registration and public access disabled unless specifically approved
- [ ] Admin, editor, reader, and guest roles mapped and negatively tested
- [ ] Ops, Community, and Sales shelf/book structure approved
- [ ] Each pilot page includes owner, reviewer, approval date, review date, and class
- [ ] Upload types/limits, attachments, external content, and scripts reviewed
- [ ] Authentication, mail, webhook, and theme features disabled unless tested
- [ ] Backup/export, monitoring, and stale-page reminders assigned
- [ ] Offline emergency copy and original source set remain available

Unchecked items block publication or require recorded risk acceptance. No setting has been applied.
