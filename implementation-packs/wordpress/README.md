# WordPress implementation pack

Operator pack for a minimal coworking marketing site with one tour-request form, a reviewed theme/plugin inventory, named publishing and technical owners, monitored lead delivery, accessibility testing, protected backups, and reversible DNS/deployment cutover.

Start with `operator-profile.yaml`, use `templates/plugin-and-form-approval.yaml`, run `recipes/staging-tour-site.md`, and retain evidence beside `examples/launch-evidence.md`. WordPress core evidence does not verify a host, theme, plugin, form, email route, accessibility outcome, or restore.
