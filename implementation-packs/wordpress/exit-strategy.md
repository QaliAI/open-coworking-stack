# Exit strategy

Maintain domain/registrar/DNS ownership, redirect map, content export, source media and rights, full backup, theme/plugin manifest and licenses, user register, form data/destinations, privacy records, analytics baseline, and unreconciled lead queue.

Build the replacement privately, import/transform content, recreate only approved features, and test redirects, accessibility, forms, fallback contact, monitoring, and export before changing DNS. Keep both lead routes supervised during cutover.

After approval, reconcile leads/content, revoke old users/keys/vendor access, remove integrations, retire host/DNS routes, and delete site data/backups under retention policy. Native export fidelity for plugin configuration and forms remains unverified until tested.
