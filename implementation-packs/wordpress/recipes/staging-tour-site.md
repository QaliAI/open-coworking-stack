# Recipe: staging tour site

1. Freeze current DNS, redirects, content, analytics, users, and fallback contact route.
2. Approve minimum pages, factual claims, theme, form solution, supporting plugins, and data destinations.
3. Create access-controlled non-indexed staging with individual users, TLS, synthetic data, and test delivery sinks.
4. Build the minimum pages and form with clear labels/errors and a direct fallback contact.
5. Run role, form success/failure/spam/duplicate, responsive, keyboard, zoom, assistive-technology, link, redirect, and performance tests.
6. Back up and restore to a second isolated location; run an approved update and rollback rehearsal.
7. Reconcile every synthetic submission and remove test data.
8. Obtain marketing, privacy, accessibility, security, lead, technical, and change approvals.
9. If approved, cut over reversibly while watching redirects and form delivery.
