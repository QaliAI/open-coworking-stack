# Seatsurfing coworking booking implementation pack

Use this pack to evaluate reservations for 20 desks already included in an approved pilot group's entitlement. Official Seatsurfing documentation states that the product has no accounting model, so paid desk sales, membership plans, and billing are excluded.

The pack contains no container manifest, secrets, production defaults, or runtime evidence. Use current official self-hosting instructions, pin versions locally, preserve the manual desk register, and complete every test before expansion.

Runtime status: **not tested**. See [the full guide](../../guides/tools/seatsurfing.md).
