# Seatsurfing pilot data map

| Data                  | Source/owner               | Purpose                   | Authority                | Exit/fallback             |
| --------------------- | -------------------------- | ------------------------- | ------------------------ | ------------------------- |
| User/group            | Approved membership roster | Identify eligible bookers | Membership system        | Roster crosswalk          |
| Area/floor image      | Facilities                 | Navigation                | Floor inventory          | Image and map register    |
| Space/desk            | Facilities                 | Bookable item             | Desk register            | CSV/manual list if tested |
| Reservation           | Member                     | Coordinate claims         | Seatsurfing during pilot | Future-booking register   |
| Utilization statistic | Reservation events         | Layout experiment         | Human-reviewed analysis  | Aggregate report          |

Classify user and reservation data as personal location/time information. Keep payment, contract, access-control, identity-document, diagnosis, and free-text member-case data out.
