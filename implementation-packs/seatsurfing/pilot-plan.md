# Pilot plan

## Scope

One floor, 20 hot desks, one approved member group, two weeks, and no paid inventory or access-control integration.

## Sequence

1. Approve rules, privacy notice, data retention, floor image, and fallback.
2. Build isolated staging using current official self-hosting guidance.
3. Replace secrets and create synthetic admin/member/denied users.
4. Validate every desk onsite and execute the test matrix.
5. Complete a clean backup/restore before importing pilot identities.
6. Run two weeks with daily exception/support review.
7. Compare aggregate reservations and feedback; review cost and exit.

Stop on map mismatch, unauthorized visibility, unclear entitlement, unhandled accessibility case, failed fallback/restore, or any request to automate billing/doors.
