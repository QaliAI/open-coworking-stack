# Configuration checklist

- [ ] Current official self-hosting and release documentation reviewed.
- [ ] Application and PostgreSQL images/versions pinned locally.
- [ ] Bootstrap/default credentials replaced before network exposure.
- [ ] `CRYPT_KEY`, database credentials, and admin recovery stored outside version control.
- [ ] TLS, restricted admin path/network, monitoring, and backups configured.
- [ ] 20 desk IDs match physical labels and approved floor image.
- [ ] Hours, timezone, duration/count, cancellation, no-show, and approval rules approved.
- [ ] User/group visibility and booking-history retention minimized.
- [ ] Membership roster remains authoritative; door/billing writes prohibited.
- [ ] Manual future-reservation register and support route prepared.
- [ ] Clean database restore passed before member pilot.
