# Coworking use cases

## In scope

- Booking 20 labeled hot desks already included in membership.
- Visual map/list selection and approved duration/count rules.
- Staff-managed exceptions and designated-space approval where configured.
- Aggregate reservation metrics reviewed alongside ordinary operations feedback.

## Poor fit and exclusions

- Commercial desk/day-pass sales: official docs state no accounting model.
- Membership entitlement, credits, invoicing, refunds, and tax.
- Door access, safety roll-call, proof of attendance, or staff/member performance monitoring.
- Location-history retention without a documented need and privacy approval.

If any excluded capability is required, evaluate a coworking management platform rather than stretching this pilot.
