# Nextcloud Coworking Implementation Pack

This pack pilots one staff operations folder with two active users and one leaver fixture. It is not a deployment manifest, storage design, identity integration, managed-host recommendation, or approval for member archives.

Complete the folder register and checklist, then follow `recipes/staff-folder-pilot.md`. Use neutral test files from `examples/` and retain the previous handoff process until permissions, sync, export, and a coordinated restore pass.

See [`guides/tools/nextcloud.md`](../../guides/tools/nextcloud.md). No server, client, app, integration, backup, restore, or upgrade has been runtime-tested here.
