# Exit Strategy

Announce a single write-freeze time and inventory folders, owners, groups, users, shares/tokens, apps, storage, and retention obligations. Download neutral file copies with hashes and map permissions to the replacement. Export calendar/contact/form data only through tested, version-specific procedures if those apps entered scope.

Test representative files and allow/deny users in the replacement, then revoke shares, app tokens, sessions, service credentials, and integrations. Remove clients and endpoints carefully to avoid deleting authoritative replacement data. Retain/delete server state and backups under policy.

File versions, comments, activity, shares, app metadata, and non-file app fidelity are not assumed portable.
