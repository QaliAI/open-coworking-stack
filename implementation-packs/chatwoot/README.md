# Chatwoot coworking enquiry-inbox implementation pack

Use this pack to pilot one limited website inbox with two agents and explicit sales, facilities, privacy, and after-hours handoffs. It is not a deployment, channel entitlement, or automated support agent.

## Entry criteria

- Inbox, daily queue, privacy, technical/recovery, website, and escalation owners named.
- Labels, assignment, response/after-hours wording, urgent fallback, prohibited data, attachments, and retention approved.
- Cloud/edition or self-host version and website-widget docs verified.

## Exit criteria

- Agent/unauthorized roles, assignment, notes/replies, after-hours, and escalation tests pass.
- Every pilot conversation and open handoff reconciles.
- Export/account recovery or clean self-host restore is accepted.

## Untested limitations

No edition, install, website widget, channel, role, MFA, notification, automation, attachment, deletion, export, backup, restore, upgrade, performance, residency, or support behavior has been tested. Additional channels need separate packs/tests.

Start with the inbox-policy template and test scorecard.
