# Chatwoot data map

| Object                   | Source         | Purpose               | Control/exit                                         |
| ------------------------ | -------------- | --------------------- | ---------------------------------------------------- |
| Contact identity/details | Visitor/member | Reply/context         | Minimize; approved CRM/manual handoff                |
| Messages                 | Visitor/agent  | Conversation          | Retention/export/deletion review                     |
| Private notes            | Agent          | Internal coordination | Restricted, factual, never visitor-facing            |
| Labels/assignment/status | Agent/system   | Workflow state        | Open-case mapping and reconciliation                 |
| Attachments              | Visitor/agent  | Supporting context    | Restrict, review/scan, retain/delete deliberately    |
| Agent account/activity   | Staff/system   | Access/operations     | Roster/offboarding; edition-dependent audit evidence |
| Channel/API secrets      | Providers      | Connectivity          | Secret custodian and source revocation               |

Payment and identity-document data are excluded. Provider copies, exports, deletion, logs, and residency are untested.
