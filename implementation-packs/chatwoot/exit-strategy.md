# Chatwoot exit strategy

1. Inventory inboxes, channels, contacts, open conversations, assignments, labels, notes, attachments, agents, webhooks, and credentials.
2. Stop new intake by removing the widget/channel at an approved time while keeping the previous contact route.
3. Export supported retained records and create a human-reviewed open-case handoff register.
4. Assign every unresolved case in the replacement/manual queue and confirm owner receipt.
5. Map labels/notes conservatively; private notes need privacy review before migration.
6. Revoke website, channel, API, mail, storage, SSO, and agent access across providers.
7. Apply retention/deletion to Chatwoot, provider copies, exports, backups, and test restores.

Export fidelity, attachment links, private-note mapping, provider deletion, and API completeness are untested.
