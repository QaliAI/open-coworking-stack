# Chatwoot configuration checklist

- [ ] Managed plan/edition or exact self-host version/image tag recorded
- [ ] One website inbox and approved page/domain scope selected
- [ ] Two individual agents; admin and inbox privileges minimized
- [ ] MFA, session, onboarding, and offboarding behavior reviewed
- [ ] Labels, assignment, ownership, response, closure, and reopen rules approved
- [ ] Operating-hours/after-hours and urgent-contact wording approved
- [ ] Public replies and private notes tested with both roles
- [ ] Attachment, prohibited-data, privacy notice, and retention rules approved
- [ ] Notifications and stale/unassigned queue alerts tested
- [ ] Sales, facilities, complaint, and visitor handoffs named
- [ ] Existing contact route remains visible and staffed
- [ ] Export/account recovery or database/storage restore assigned

Do not add email/social/bot/API channels from this checklist. No configuration is applied.
