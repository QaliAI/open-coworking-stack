# Coworking use cases

## Approved pilot

Provide guest internet and staff access on separate approved test VLANs in one area. Community staff test ordinary member workflows; the network operator verifies isolation and handles changes.

## Later, separately reviewed uses

- Standardize approved SSID and network intent across locations.
- Correlate device/uplink health with member-reported Wi-Fi incidents.
- Schedule human-approved maintenance and configuration backups.

## Out of scope

Captive-portal identity, door or life-safety dependencies, employee/member tracking, automated blocking, and unsupported third-party integrations are not authorized by this pack.
