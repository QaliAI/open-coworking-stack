# Configuration checklist

- [ ] Controller and every test device model/version recorded
- [ ] Current topology, IP plan, VLANs, DHCP/DNS, uplinks, PoE, and cabling mapped
- [ ] Guest, staff, management, and infrastructure policy approved
- [ ] Management access isolated; named admin and recovery access tested
- [ ] Guest-to-private and guest-to-guest behavior explicitly configured and tested
- [ ] Optional identification/analytics disabled unless privacy-approved
- [ ] Device names and physical locations match inventory
- [ ] Firmware automatic rollout disabled for the pilot
- [ ] Independent monitoring and member communication route assigned
- [ ] Backup, restore target, stop conditions, and incumbent failback ready

The network operator must annotate each item with controller/device versions and evidence. A checked box without an observation is not acceptance.
