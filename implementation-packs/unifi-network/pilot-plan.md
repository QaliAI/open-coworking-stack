# Pilot plan

## Scope

One isolated area, approved test AP/switch/gateway as needed, one guest SSID, one staff SSID, synthetic/test clients, and no production captive portal, access control, payment, or life-safety dependency.

## Gates

1. Network, facilities, privacy, and change owners approve design and data handling.
2. Backup and incumbent failback are available before device adoption.
3. Isolation and critical workflow tests pass before invited staff use.
4. A limited user window runs with community support present.
5. Expansion requires evidence review; it is not automatic.

## Stop conditions

Stop for cross-network access, DHCP/DNS failure, repeated disconnects, unacceptable coverage/capacity, lost administration, missing backup, or a failed critical workflow. Fail back and record the result.

No runtime test has been executed by this repository. Operators set thresholds from a measured site baseline.
