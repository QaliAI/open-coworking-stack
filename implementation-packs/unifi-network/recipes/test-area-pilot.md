# Recipe: one-area segmentation pilot

1. Select a test area with the incumbent Wi-Fi still available.
2. Photograph/map approved test hardware and record controller/device versions.
3. Obtain approved test IP/VLAN, DHCP/DNS, firewall, SSID, and minimum-telemetry design.
4. Back up the controller and confirm independent recovery access.
5. Stage devices without prematurely adopting production hardware.
6. Connect synthetic guest/staff devices and run the required isolation and workflow matrix.
7. Simulate controller unavailability and execute the approved failback without changing production dependencies.
8. Record observations, help-desk feedback, and stop-condition status.
9. Have network, privacy, facilities, and change owners sign the evidence record.

This recipe deliberately omits UI click paths because they are version-dependent; record the official version-matched source used.
