# UniFi Network implementation pack

Operator pack for a reversible guest/staff Wi-Fi segmentation pilot on already approved UniFi hardware. Start with `operator-profile.yaml`, record approvals in `templates/change-record.yaml`, execute `recipes/test-area-pilot.md`, and retain results beside `examples/pilot-evidence.md`.

This pack contains procedures, not proof of deployment. Hardware compatibility, RF design, telemetry behavior, backup portability, and recovery times remain unverified until the operator records version- and site-specific evidence. Use current [official help](https://help.ui.com/) before every change.

Do not use this pack for life-safety networks, autonomous client blocking, or an unreviewed production cutover.
