# Recipe: five-SOP operations home

1. Select current copies of opening, closing, tour, room-reset, and escalation SOPs.
2. Record a source checksum or immutable source version, owner, and review date.
3. Create a private operations home and one page per SOP.
4. Grant staff only the access they need; test with an unauthorized account.
5. Create a separate synthetic contractor page, invite one guest, verify scope, and revoke.
6. Export HTML and Markdown/CSV with attachments.
7. On a clean machine, reconstruct an index linking all five exported SOPs.
8. Complete an evidence record and request the four-person approval gate.

Do not move safety-critical authority or delete source copies during this recipe.
