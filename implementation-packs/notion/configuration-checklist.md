# Configuration checklist

- [ ] Current plan limits and billing verified from official pricing.
- [ ] Two approved workspace owners and recovery contacts recorded.
- [ ] Private operations home created; web publishing disabled/not used.
- [ ] Staff groups use least privilege; broad workspace access reviewed.
- [ ] Five pages have source, owner, classification, and review date.
- [ ] Guest invitation requires manager approval and expiry/offboarding task.
- [ ] Public links and connected apps reviewed before pilot and monthly.
- [ ] AI, forms, automations, and connections excluded unless separately approved.
- [ ] Protected external export destination approved.
- [ ] Existing staff index remains available through rollback.
