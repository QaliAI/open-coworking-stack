# Pilot plan

## Scope

Five copied non-critical SOPs, one private operations home, staff test accounts, and one controlled guest on a separate synthetic page.

## Sequence

1. Baseline source files, owners, users, and expected attachments.
2. Configure private structure and least-privilege groups.
3. Migrate copies; test staff search/edit and unauthorized denial.
4. Invite the test guest, verify limited access, then revoke it.
5. Export HTML and Markdown/CSV with files.
6. Reconstruct a clean fallback index and record losses.
7. Review labor, cost, privacy, and user feedback.

## Stop conditions

Stop on unexpected access, missing/unreadable export content, failed account recovery, sensitive data in scope, or no named content owner. Expansion requires signed evidence, not elapsed pilot time.
