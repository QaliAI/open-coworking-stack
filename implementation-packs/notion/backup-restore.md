# Backup, export, and recovery

Notion exports are portability/fallback artifacts, not an operator-controlled restoration of the SaaS workspace.

1. Inventory five pages, databases, attachments, owners, and accessible comments.
2. Export scoped content as HTML and Markdown/CSV with files.
3. Store the archive in an approved restricted location outside Notion.
4. Extract on a clean machine; open every page and attachment.
5. Reconcile expected counts and database columns.
6. Build a navigation index and identify links, views, permissions, comments, or behavior that did not survive.
7. Record export account, timestamps, plan, result, reviewer, and next test.

Pass only when operations can use the reconstructed five-page fallback. Official help states a workspace export cannot be instantly recreated by re-uploading it.
