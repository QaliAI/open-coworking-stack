# Exit strategy

1. Maintain a page/database/owner inventory and field dictionary throughout use.
2. Freeze edits and record the cutover time.
3. Export each used content type in officially supported formats with files.
4. Reconcile inventory, attachments, and critical fields; document losses.
5. Transform links, database fields, and page hierarchy for the destination.
6. Run user acceptance against the destination and retain a read-only fallback.
7. Remove guests, integrations, and users; settle billing and obtain available closure/deletion confirmation.

Engage a migration specialist if critical relations, automations, or content volume cannot be manually reconciled.
