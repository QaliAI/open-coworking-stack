# Odoo Community Coworking Evaluation Pack

This pack evaluates CRM and invoice workflow shape using ten synthetic leads in an isolated Odoo Community database. It is not a production ERP design, accounting approval, booking/access integration, version migration, or claim that Enterprise-marketed features exist in Community.

Freeze the exact Odoo version, source/package, and installed technical modules in the operator profile. Run `recipes/synthetic-crm-invoice.md` with the example CSV only after finance and technical reviewers approve the fixture model.

See [`guides/tools/odoo-community.md`](../../guides/tools/odoo-community.md). Modules, localization, import/export, backup, restore, update, upgrade, and integrations are not runtime-verified here.
