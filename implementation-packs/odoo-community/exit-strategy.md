# Exit Strategy

For the synthetic evaluation, export contacts/leads, stages, products, invoice sample, users, and External IDs; preserve attachments separately; record modules, custom fields, workflows, and role assumptions; then delete the isolated instance and backups after the evidence-retention period.

Before any future production exit, freeze writes and reconcile record counts and financial totals with qualified finance review. Revoke users/integrations and test replacement imports in dependency order using stable External IDs.

CSV/XLS portability does not imply preservation of chatter, attachments, permissions, automation, module fields, or complete accounting relationships. Those remain migration work.
