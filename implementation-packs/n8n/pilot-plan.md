# Lead Handoff Pilot

## Week zero

Build against test systems with the workflow inactive. Run every fixture and reconcile source/execution/destination outcomes.

## Limited run

After approval, accept only a clearly identified low-risk pilot source for one week. The coordinator checks failures, uncertain outcomes, duplicates, and count mismatch each business day. All qualification and replies remain manual.

## Stop conditions

Stop on unexplained loss/duplicate, credential exposure, uncertain writes without lookup, unavailable exception owner, source schema change, or sensitive payload. Switch to manual intake immediately.

## Pass gate

Zero silent loss and duplicate, all fixture outcomes match, alerts are observed, fallback works, execution retention is approved, and a clean inactive restore passes.
