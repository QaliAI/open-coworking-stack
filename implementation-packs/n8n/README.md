# n8n Coworking Implementation Pack

This pack evaluates one reversible lead handoff: approved web-form records to a test CRM/register plus a staff status notification. It provides governance and test artifacts, not a deployable n8n instance or a verified connector.

Complete the workflow contract and field map before opening the editor. Use `examples/lead-fixtures.json` only with test systems, then follow `recipes/lead-handoff.md`. Keep the workflow inactive until the process, data, and integration owners sign.

See [`guides/tools/n8n.md`](../../guides/tools/n8n.md). Runtime, node, API, credential recovery, and license fit are not proven here.
