# Coworking Use Cases

## Pilot use case

Copy an approved website inquiry into a test lead register and send staff a status containing the source ID, not the full inquiry body.

## Potential next use cases

- Notify an owner that an event-interest form needs manual review.
- Produce a daily mismatch report between two systems without changing either.
- Create a staff task after a confirmed low-risk status change.

Each next use case gets a separate contract and credentials. Exclude member eligibility, contracts, invoicing/payment/refunds, door access, identity checks, safety incidents, disputes, employment, and emergency workflows.
