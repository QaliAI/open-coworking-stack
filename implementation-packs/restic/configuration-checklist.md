# Configuration checklist

- [ ] Protected application version and official consistency procedure recorded.
- [ ] Recovery data-loss/time objectives approved, not assumed.
- [ ] Restic binary pinned and checksum/source verification recorded.
- [ ] Offsite documented backend and failure-domain review complete.
- [ ] Repository credential and password are separate and least privilege.
- [ ] Two approved password custodians can recover without source host.
- [ ] Include/exclude paths and tags reviewed by application owner.
- [ ] Job exit status, last snapshot age, capacity, and failures monitored.
- [ ] Retention command is reviewed and destructive maintenance needs approval.
- [ ] Clean isolated restore host and database tooling available.
- [ ] Existing backup process remains active until sign-off.
