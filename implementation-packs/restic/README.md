# Restic coworking recovery implementation pack

Use this pack to prove recovery of one non-critical self-hosted coworking service from an offsite Restic repository to a clean host. A successful scheduled job is not acceptance.

This pack does not include a storage provider, credentials, repository password, scheduler, or production command. Select a backend documented by Restic, fill `operator-profile.yaml`, adapt the recipe to the application's official consistency method, and retain evidence with the provided template.

Runtime status: **not tested**. Keep the existing backup process active through the pilot.
