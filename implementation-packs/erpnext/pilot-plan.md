# Pilot plan

1. Process owner writes one membership/invoice scenario and finance writes independent expected totals and statuses.
2. Technical owner creates isolated staging using current official guidance and records versions/apps.
3. Finance and security approve minimum roles/configuration; data owner confirms synthetic-only input.
4. Operator performs create, review, submit, correction/cancellation, reconciliation, and export cases.
5. Finance compares every output to the expected-results sheet and records differences.
6. Technical owner backs up and restores to clean staging; finance rechecks restored outputs.
7. Team rehearses outage fallback and export/exit.
8. Sponsor decides reject, revise, or commission a separately scoped expert-led phase.

Stop for unexplained totals, uncontrolled permissions, real data, failed export/restore, app incompatibility, or inability to reconcile.
