# ERPNext implementation pack

Use this pack to evaluate one synthetic coworking membership item, customer, and invoice lifecycle in isolated staging. It is not a production accounting migration, localization opinion, or substitute for qualified accounting review.

Complete `operator-profile.yaml`, approve configuration and data boundaries, follow `recipes/synthetic-invoice-pilot.md`, and record evidence with the template. The example is synthetic.

Official sources reviewed 2026-07-17: [ERPNext](https://erpnext.com/), [documentation](https://docs.erpnext.com/), [repository](https://github.com/frappe/erpnext), and [official pricing](https://frappe.io/erpnext/pricing). Re-check current version, hosting, support, and app information.
