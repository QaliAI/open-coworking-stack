# Configuration checklist

- [ ] Record selected ERPNext/Frappe version, hosting model, and official support source.
- [ ] Isolate staging; allow synthetic data only.
- [ ] Finance approves test chart, currency, fiscal context, taxes, and expected results.
- [ ] Process owner approves one item/customer/invoice lifecycle and exclusions.
- [ ] Separate administrator, finance reviewer, and operator roles where feasible.
- [ ] Configure TLS, restricted administration, updates, monitoring, and protected backups.
- [ ] Disable or ignore modules outside pilot; inventory every app/customization.
- [ ] Keep payment credentials and live integrations out.
- [ ] Define record identifiers and reconciliation procedure.
- [ ] Verify representative exports before any migration discussion.
- [ ] Approve stop conditions, current-process fallback, restore, and destruction of test data.
