# Backup and restore

Use official procedures appropriate to the selected version/hosting model to protect the site database, files, site configuration, encryption/secret material required for recovery, app/version inventory, and external dependency notes. Keep credentials outside the pack.

Restore to clean isolated staging. Verify synthetic customer/item/invoice, workflow status, roles, reports, files if used, and export behavior. Finance reconciles restored totals to the independent sheet. Record duration and omissions.

A successful backup command or downloadable file is not restore evidence. Production recovery objectives, managed-host restore behavior, and app recovery remain unproven until observed.
