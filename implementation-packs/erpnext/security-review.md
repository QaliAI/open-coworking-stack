# Security review

Review host/service exposure, TLS, administrative access, role separation, database and file access, secrets, updates, audit/event visibility in the selected configuration, backups, apps/custom code, outbound connections, retention, and incident ownership.

Finance must confirm that permissions support the approved review and posting process. The data owner must confirm no production or payment credentials entered staging. Record observed controls, not assumptions based on another edition/version.

Obtain specialist security review before public exposure, SSO, payment/bank integration, custom apps, or sensitive data. Obtain accounting/tax and privacy/legal advice before production financial or personal records. This pack is not a security, accounting, or compliance certification.
