# Recipe: one support mailbox pilot

1. Create staff-authored test messages for ordinary IT, facilities handoff, attachment, duplicate/threading, reopen, and prohibited emergency scenarios.
2. Configure one alias using current FreeScout and provider documentation without disabling source-mailbox access.
3. Add only named pilot agents and test private-note/admin boundaries.
4. Approve a canned acknowledgement that says a person will review it and directs emergencies elsewhere.
5. Process synthetic cases end to end, then run the live 14-day scope if all owners approve.
6. Daily, compare source mailbox identifiers/counts to the queue and record differences.
7. End by exporting/reconciling open cases, restoring a backup, and returning routing to the mailbox.

Provider-specific DNS and connection values are intentionally omitted until verified.
