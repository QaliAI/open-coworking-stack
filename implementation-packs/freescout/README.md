# FreeScout implementation pack

Use this pack for a 14-day pilot of one coworking support alias with a small agent group, explicit facilities escalation, and an emergency route outside email. It does not establish provider compatibility, deliverability, privacy compliance, or production readiness.

Approve the operator profile and checklist, run the mailbox recipe first with synthetic messages, and capture evidence in the template. The supplied example is synthetic.

Official sources reviewed 2026-07-17: [FreeScout](https://freescout.net/), [repository](https://github.com/freescout-help-desk/freescout), [wiki](https://github.com/freescout-help-desk/freescout/wiki), and [modules](https://freescout.net/modules/). Verify current core/module terms and version-specific guidance.
