# Pilot plan

1. Document current mailbox counts, owners, response process, vendor handoff, and emergency route.
2. Deploy isolated staging and test with staff-authored messages, including attachments and failure cases.
3. Approve roles, templates, retention, modules, and mailbox behavior.
4. Route one alias for 14 days while retaining the source mailbox and emergency channel.
5. Reconcile source mailbox to queue daily; review unassigned/overdue/reopened and sample closures.
6. Test agent offboarding, export/return of open cases, backup, and clean restore.
7. Roll back mail routing and reconcile every remaining case.
8. Owners decide reject, revise, or approve a separately scoped rollout.

Stop for lost/duplicate mail that cannot be reconciled, sensitive-data leakage, unauthorized notes, deliverability failure, emergency misrouting, or failed rollback.
