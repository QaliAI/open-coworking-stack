# Data map

| Data                   | Source/purpose       | Access                     | Retention/exit                         |
| ---------------------- | -------------------- | -------------------------- | -------------------------------------- |
| Message headers/body   | Member/staff support | Assigned agents            | Approved mailbox/case retention        |
| Contact details        | Message headers      | Agents with case need      | Minimize; export/delete by policy      |
| Attachments            | Sender; case context | Restricted agents          | Scan/restrict; delete by policy        |
| Tags/status/assignment | Agents/rules         | Agents/managers            | Export/map with open cases             |
| Private notes          | Staff coordination   | Explicitly permitted roles | Restrict and include in privacy review |
| Mailbox credentials    | Provider connection  | Runtime/admin secret       | Rotate on rollback/exit                |

Do not solicit card/bank credentials. Define procedures for identity, health, legal, harassment, surveillance, or access-related content before live use; this pack provides no legal basis or retention determination.
