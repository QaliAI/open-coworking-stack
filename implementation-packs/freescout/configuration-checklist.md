# Configuration checklist

- [ ] Preserve source mailbox access and record message-count reconciliation method.
- [ ] Publish the separate emergency/safety channel in acknowledgements and staff guidance.
- [ ] Use named least-privilege agents; test administrator and private-note boundaries.
- [ ] Verify inbound/outbound settings with provider documentation and synthetic messages.
- [ ] Approve sender name, acknowledgement wording, categories, tags, and response expectations.
- [ ] Name facilities/vendor escalation owner and spending/authorization boundary.
- [ ] Approve attachment types/size, malware handling, PII minimization, and retention.
- [ ] Inventory each module with source, license/terms, cost, permissions, and compatibility.
- [ ] Configure TLS, updates, backups, monitoring, and credential storage.
- [ ] Define duplicate, delivery-failure, overdue, reopen, and outage procedures.
- [ ] Obtain mailbox, facilities, privacy, technical, and pilot-owner approvals.
