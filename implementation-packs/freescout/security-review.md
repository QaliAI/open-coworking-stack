# Security review

Review Internet exposure, TLS, administrator/agent roles, authentication options actually available, mailbox credentials, outbound identity, updates, database/files, attachment handling, private notes, backups, logs, modules, outbound integrations, retention, and incident response.

Privacy reviews exact collected fields, acknowledgement language, agent access, retention/deletion, exports, and subject-request procedure. Facilities confirms email is not emergency dispatch and approves vendor escalation authority.

Obtain specialist review before SSO, custom/public modules, regulated content, large migration, or public production deployment. Module listings and core licensing do not prove module security, maintenance, terms, or compatibility.
