# Paperless-ngx coworking document implementation pack

Use this pack to evaluate 20 historical supplier invoices in isolated staging. Retain every original and exclude member mail, contracts, identity documents, and payment credentials until separate records, privacy, legal, and security review.

The pack references official installation, exporter/importer, sanity-check, and upgrade procedures but does not vendor Paperless-ngx or provide a production Compose file. Pin versions locally and do not claim recovery until an empty matching-version import passes.

Runtime status: **not tested**. See [the full guide](../../guides/tools/paperless-ngx.md).
