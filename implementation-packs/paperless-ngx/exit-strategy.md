# Exit strategy

1. Maintain document IDs, source/original inventory, taxonomy dictionary, owners/access mapping, and exact application version.
2. Stop intake and timestamp the content freeze.
3. Use the official exporter for originals, archive files, thumbnails if needed, manifest, metadata, and database content.
4. Reconcile document/page/file counts and checksums where available; preserve originals.
5. Map correspondent, document type, tags, dates, custom fields, users, and permissions to the destination.
6. Test destination retrieval, search, access denial, and records retention with business owners.
7. Revoke accounts/tokens and delete old primary/export/backup data only after records/privacy approval and retention expiry.

Engage a migration specialist when volume or metadata relationships cannot be manually reconciled.
