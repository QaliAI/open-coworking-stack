# Keycloak implementation pack

Use this pack for one isolated staging realm, one non-critical OIDC application, two test staff identities, disablement, outage fallback, restore, and rollback. It excludes production federation, member identity, physical access, and high availability.

Approve the profile/checklist, follow `recipes/one-oidc-client.md` using current official documentation, and record evidence with the template. The example is synthetic.

Official sources reviewed 2026-07-17: [Keycloak](https://www.keycloak.org/), [documentation](https://www.keycloak.org/documentation), and [repository](https://github.com/keycloak/keycloak). Re-check selected-version deployment, upgrade, and protocol guidance.
