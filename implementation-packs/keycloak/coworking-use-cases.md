# Coworking use cases

## Pilot use case

Connect one non-critical staging wiki, help desk, or booking test application through OIDC. Give two test staff users minimum claims, disable one by approved request, terminate its session, and prove the application returns to its prior login.

## Potential later scope requiring new review

- Additional staff applications.
- Federation to an authoritative workforce directory.
- More complex MFA or authentication flows.

## Exclusions

Keycloak authenticates; people and applications authorize. It does not determine employment, membership, proofing exceptions, building/door access, discipline, or emergency entry. No physical-access integration belongs in this pilot.
