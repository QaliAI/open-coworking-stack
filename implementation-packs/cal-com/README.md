# Cal.com coworking tour-booking implementation pack

Use this pack to pilot one Tour Booking event type, one host calendar, and five bookings while preserving a manual enquiry route. It is not a self-host deployment or a statement that any Cal.com plan has the required features.

## Entry criteria

- Scheduling owner, host, calendar admin, privacy reviewer, and technical/recovery owner named.
- Tour hours, buffers, conflict rules, fields, notices, no-show/escalation, and retention approved.
- Deployment/plan and calendar integration verified against current official sources.

## Exit criteria

- Five bookings reconcile to the authoritative calendar without tested conflicts.
- Notifications, cancellation/reschedule, token revocation, and manual fallback pass.
- Export/account recovery or self-host restore evidence is accepted.

## Untested limitations

No plan, self-host install, calendar provider, conflict rule, time zone, notification, workflow, API, export, deletion, backup, restore, upgrade, support, residency, or performance behavior has been tested. Verify current feature/edition boundaries.

Start with the event-type template and booking test matrix.
