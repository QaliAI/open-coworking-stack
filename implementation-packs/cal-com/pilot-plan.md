# Cal.com pilot plan

## Configure

Complete `templates/tour-event-review.yaml` for one host. Use a test calendar/account where possible, minimum attendee fields, no payment, and a limited booking link.

## Test

Run the cases in `examples/booking-test-matrix.csv`, including two people attempting the same slot, time-zone display, notice/buffer boundaries, messages, reschedule/cancel, and credential revocation.

## Operate

Process five approved bookings in one week. Reconcile each to the calendar, attendee message, host action, visitor arrival outcome, and any CRM handoff. Track no-shows and manual work without staffing claims.

## Decide

Scheduling, host, privacy, and visitor-operations owners approve, defer, or roll back. Do not expand to rooms, payments, or workflows on tour evidence alone. All behavior is currently untested.
