# Cal.com recovery plan

## Managed SaaS

Verify supported booking/attendee export, administrator/account recovery, credential revocation, and provider incident process. Maintain an independent list of upcoming bookings and the authoritative host calendar so manual scheduling can resume. Provider backup is not the same as operator restore.

## Self-hosted

From the exact selected release's official guidance, inventory database, configuration, application state, credentials/references, jobs, and integration setup. Create a consistent protected backup and restore it into an isolated environment.

## Acceptance

Verify one event type, rules, host role, five representative bookings, calendar reconnection with test credentials, notifications in a safe sink, and no contact with real attendees. Exact backup/export coverage is unverified and this drill is not run.
