# Cal.com exit strategy

1. Inventory event types, hosts, upcoming bookings, workflows/webhooks, integrations, and credentials.
2. Stop promotion and unpublish links at an approved time while keeping a staffed manual route.
3. Export supported booking/attendee records and reconcile them to authoritative calendars and open visitor tasks.
4. Notify affected attendees of changed links or handling where necessary.
5. Recreate only approved rules in the replacement and run conflict/time-zone/message tests.
6. Revoke calendar OAuth tokens, API keys, webhooks, mail/video credentials, and administrator access.
7. Apply retention/deletion to service, providers, exports, test restores, and backups.

Export fidelity, workflow portability, and deletion propagation are untested; manual reconciliation is mandatory.
