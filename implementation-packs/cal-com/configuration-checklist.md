# Cal.com configuration checklist

- [ ] Managed/SaaS or self-host choice and exact plan/version recorded
- [ ] Required event/calendar features confirmed from current official sources
- [ ] One named host, authoritative calendar, and backup owner approved
- [ ] Calendar scopes minimized; token owner and revocation tested
- [ ] Tour duration, time zone, hours, notice, window, buffers, and conflicts recorded
- [ ] Location, capacity, cancellation, reschedule, and no-show text approved
- [ ] Form fields minimized; privacy, consent, retention, and accessibility route reviewed
- [ ] Host/attendee notifications tested for correct content and failure visibility
- [ ] CRM and visitor-arrival handoffs remain human-owned
- [ ] Manual booking route remains visible and staffed
- [ ] Export/account recovery or self-host backup/restore test assigned
- [ ] Link can be unpublished quickly by a named operator

No setting or credential is supplied by this pack. Unchecked items block publication.
