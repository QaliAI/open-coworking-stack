# Data map

| Data                              | Location/flow                | Access                               | Retention/exit                                  |
| --------------------------------- | ---------------------------- | ------------------------------------ | ----------------------------------------------- |
| Page/referrer and request signals | Browser to Umami             | Restricted marketing analysts/admins | Minimum approved retention; aggregate export    |
| Fixed tour CTA event              | Browser to Umami             | Marketing and privacy-approved users | Event dictionary and dated counts               |
| Device/browser metadata           | Generated by requests/config | Restricted dashboard/data operators  | Verify actual fields; minimize/delete by policy |
| Site definitions and users        | Umami administration         | Named least-privilege admins         | Configuration/access register                   |
| Self-host database/backups        | Managed infrastructure       | Technical/recovery owners            | Encrypted off-host copy and tested retirement   |

Names, emails, phone numbers, form contents, member/lead IDs, payment data, and sensitive URL parameters are prohibited. Inspect the selected configuration: the table is a design boundary, not proof of actual collection.
