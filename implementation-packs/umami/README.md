# Umami implementation pack

Operator pack for a staging-first coworking marketing analytics pilot: one approved business question, one tour CTA event, and no personal data in event values. Start with `operator-profile.yaml`, use `templates/event-approval.yaml`, execute `recipes/staging-cta-pilot.md`, and retain results beside `examples/count-evidence.md`.

This pack is not legal advice and does not prove that a configuration is anonymous, consent-exempt, correctly sized, recoverable, or supported. Recheck current [official documentation](https://umami.is/docs), cloud terms, and selected-version behavior.
