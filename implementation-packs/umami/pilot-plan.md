# Pilot plan

## Scope

One staging domain, one landing page, one synthetic tour CTA event, named test dashboard users, and no production or real lead data.

## Gates

1. Marketing approves the question and expected synthetic sequence.
2. Privacy approves the schema, request inspection, notice/consent test, retention, and deletion.
3. Web confirms the site and form work with tracking blocked.
4. Technical/recovery owners pass export plus the applicable recovery test.
5. Production remains a separately approved reversible pilot.

## Stop conditions

Stop for a prohibited value, unexpected production request, unexplained duplication outside tolerance, blocked site/form, unauthorized dashboard access, failed deletion, or missing rollback/recovery evidence.

No count tolerance or runtime result is supplied by this repository; operators define and record them before generating synthetic events.
