# Recipe: staging tour CTA

1. Write one question and a synthetic browsing sequence with expected page/event counts.
2. Approve one fixed event name and an empty or allowlisted non-personal property set.
3. Configure only the staging domain with named least-privilege users.
4. Deploy the documented script through one approved mechanism.
5. Inspect browser requests and selected-version stored fields before reading dashboards.
6. Run the synthetic sequence, duplicate navigation, blocked-script, consent, sensitive-query, and form-function tests.
7. Export the aggregate result and run self-host restore or cloud recovery checks.
8. Delete pilot data and verify the disable switch.
9. Obtain marketing, privacy, web, security, and change decisions before production.

Record unexplained count variance as a failed or inconclusive test, not as user behavior.
