# Configuration checklist

- [ ] Cloud or self-host decision includes terms, recovery, export, retention, and exit
- [ ] Staging and production domains are distinct and correctly registered
- [ ] One business question and one fixed event name approved
- [ ] Event properties use an allowlist with no personal/free-text values
- [ ] Actual tracking requests and stored fields inspected
- [ ] Notice/consent and retention/deletion decisions recorded
- [ ] Named dashboard users have least privilege and tested recovery
- [ ] Script failure does not block content or the tour form
- [ ] Production disable switch and deletion owner identified
- [ ] Self-host backup restore or cloud export/account recovery tested

Attach screenshots or request/database observations with secrets and personal data removed. A configuration screenshot alone is not privacy evidence.
