# Configuration checklist

- [ ] Unofficial server and lack of official Bitwarden support accepted in writing
- [ ] Canonical HTTPS domain, maintained proxy, and exact client URLs tested
- [ ] Public signup disabled; invitations and optional email behavior approved
- [ ] Admin page/token restricted and token stored as current official guidance requires
- [ ] Individual accounts, unique master passwords, supported MFA, and recovery codes active
- [ ] Organization owners and Facilities collection membership minimized
- [ ] Optional attachments/Sends/clients reviewed and included in recovery if enabled
- [ ] Backups encrypted off-host; recovery material held separately
- [ ] Joiner/leaver, lost-device, emergency, and incident procedures assigned
- [ ] Protected export/import and isolated full-state restore passed before real migration

Record exact server/client versions and observations without secret values.
