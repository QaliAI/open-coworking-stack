# Recipe: one facilities credential

1. Select a low-impact Wi-Fi admin credential whose source system supports immediate rotation.
2. Approve two individual test users, one collection, selected clients, and explicit exclusions.
3. Deploy privately with TLS, closed signup, restricted admin access, and protected recovery custody.
4. Use a fake item to test supported MFA, sync/lock, collection deny, user removal, backup/restore, and protected export/import.
5. Re-add only approved users and migrate the one credential without recording it in tickets/evidence.
6. Rotate the password at the source network system and update the approved vault item.
7. Confirm the new credential works, the old credential fails, and the removed test user cannot use the tested access path.
8. Preserve the prior approved store only until security and credential owners accept evidence.
9. Destroy temporary export artifacts with two-person sign-off.
