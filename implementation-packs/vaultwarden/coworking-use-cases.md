# Coworking use cases

## Approved pilot

Create individual accounts for two synthetic staff users, a Facilities collection, and a fake Wi-Fi admin item. After security/recovery tests pass, migrate one low-impact real Wi-Fi admin credential, rotate it at the network system, and confirm the old password fails.

## Later, separately reviewed uses

- Store vendor-portal credentials in owner-specific collections.
- Support staff/vendor offboarding through vault revocation plus source-system rotation.
- Produce a human-reviewed collection membership report.

## Out of scope

Dynamic application secrets, payment data, life-safety or emergency door credentials, personal vault monitoring, bulk migration, and official Bitwarden support/certification claims are not authorized.
