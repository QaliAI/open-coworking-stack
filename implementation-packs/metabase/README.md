# Metabase Coworking Implementation Pack

Use this pack to prove one occupancy metric on a sanitized reporting source. It deliberately excludes production writes, public links, embedding, actions, editable tables, uploads, transforms, and assumed premium controls.

Agree `templates/metric-contract.md`, build the neutral example view for the operator's actual database, and follow `recipes/occupancy-dashboard.md`. The booking system remains authoritative; the dashboard is accepted only after independent calculation and permission tests.

See [`guides/tools/metabase.md`](../../guides/tools/metabase.md). No driver, dashboard, restore, edition feature, or coworking source has been runtime-verified by this repository.
