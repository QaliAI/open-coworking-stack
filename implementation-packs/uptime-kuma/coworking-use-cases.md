# Coworking use cases

## Approved pilot

Monitor five authorized endpoints representing the public website, booking route, Wi-Fi portal, CRM login, or payment-link landing page. Each alert goes to a named test recipient who manually validates the actual workflow.

## Later, separately reviewed uses

- Certificate-expiry warning for operator-controlled domains.
- Private operational status for staff during incidents.
- Heartbeat context for incident retrospectives under limited retention.

## Out of scope

SLA certification, transaction correctness, public provider scoring, broad credentialed probes, automatic restarts/DNS changes, and public incident publication are not authorized by this pack.
