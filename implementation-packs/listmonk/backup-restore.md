# Backup and Restore

Back up a consistent PostgreSQL state, active configuration, deployment/version record, and configured upload/media storage. Protect backup and SMTP credentials separately. Keep one copy outside the primary host.

Restore to an isolated hostname with outbound SMTP blocked. Verify application login, roles, internal list count, suppressed fixture, segment count, template, campaign history required by policy, and uploaded asset if used. Re-enable only test SMTP after privacy/technical review.

Record artifact IDs, timestamps, list/suppression counts, recovery duration, failures, and approvers. A database dump that has not been restored is not accepted recovery evidence.
