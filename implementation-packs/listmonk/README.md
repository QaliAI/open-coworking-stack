# listmonk Coworking Implementation Pack

Use this pack to pilot consent-based member or event newsletters with listmonk. It is an operator pack, not a production deployment, legal opinion, SMTP contract, or verified CRM connector.

Start with `operator-profile.yaml`, then complete `data-map.md`, `configuration-checklist.md`, and `pilot-plan.md`. Run `recipes/internal-campaign-pilot.md` with `examples/pilot-subscribers.csv`. Record every approval in `templates/campaign-approval.md`.

The corresponding guide is [`guides/tools/listmonk.md`](../../guides/tools/listmonk.md). All runtime, deliverability, webhook, restore, and integration claims remain untested in this repository.
